# 技術リファレンス管理

このディレクトリは、機能実装やインフラ構築に先立って調査した「確実な技術リファレンス」を蓄積・共有するための保管場所です。

## 目的
AIエージェントによる開発において、記憶や推測に基づく当てずっぽうなコード生成、存在しない引数の指定、IAM権限の誤設定、ライブラリの古い書き方による手戻りとトークン浪費を防ぐために設置しています。

## 運用ルール
1. **実装前の作成義務**:
   新しいライブラリ導入、外部API連携、クラウドインフラ設定、予測モデルの指標追加等を行う際は、コードを書く前に必ず調査結果をこのディレクトリにファイルとして作成してください。
2. **テンプレートの利用**:
   [template.md](./template.md) を複製して作成してください。
3. **ファイル命名規約**:
   - `lib-<パッケージ名>.md` (例: `lib-pandas.md`, `lib-pydantic.md`)
   - `cloud-<サービス名>.md` (例: `cloud-run.md`, `cloud-iam.md`)
   - `api-<外部サービス名>.md` (例: `api-sports-data.md`)
   - `infra-<対象名>.md` (例: `infra-docker.md`, `infra-sqlite.md`)
4. **セッション・エージェント間の引き継ぎ**:
   AntigravityとClaude Codeのどちらが調査した場合でもここにコミットし、後続のプロンプトや別のエージェントが再調査なしで利用できるようにします。
